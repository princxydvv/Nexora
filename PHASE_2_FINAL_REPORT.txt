🎓 KEY ARCHITECTURAL DECISIONS

  1. Single Source of Truth
     → All plans defined in lib/billing/plans.ts
     → Used by pricing, checkout, API routes, feature gates

  2. Service Role Pattern
     → Webhooks use service role client (bypasses RLS)
     → Signature verified first, so only Razorpay can trigger

  3. Atomic Database Operations
     → PostgreSQL functions for multi-step operations
     → All-or-nothing semantics, no partial updates

  4. Backend Feature Gates
     → All limits enforced server-side
     → Frontend can't be bypassed by calling API directly
